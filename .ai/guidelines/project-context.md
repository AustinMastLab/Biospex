# Project Context (BIOSPEX)

## Data Stores
- Relational DB: MySQL (e.g., Expeditions, Projects).
- NoSQL DB: MongoDB via the `mongodb/laravel-mongodb` package (e.g., Subject data, Occurrences).

## Where to Work
- For web app logic, controllers, services, Eloquent models, etc., look in `biospex/app/`.

## Running Commands
- Run Artisan commands from the `biospex/` directory.
